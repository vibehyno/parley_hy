# 프로젝트 관리 모달 및 왼쪽 메뉴 툴팁 설계

## 목적

- 왼쪽 메뉴의 현재 프로젝트 이름을 프로젝트 관리 진입점으로 변경
- 연결 프로젝트의 추가·수정·삭제·선택·상태 확인 기능을 한 화면에 제공
- 왼쪽 메뉴 기능을 처음 보는 사용자도 툴팁으로 용도를 바로 이해하도록 개선

## 접근 방식

1. 기존 설정 모달 유지: 구현 범위는 작지만 프로젝트 관리 기능이 다른 설정 사이에 묻힘
2. 항목별 즉시 반영: 조작은 빠르지만 현재 경로 변경 시 모델 세션이 바로 초기화될 수 있음
3. 전용 모달에서 편집 후 적용: 변경 내용을 확인한 뒤 한 번에 저장 가능

선택 방식: 3번. 프로젝트 관리 기능을 전용 모달에 모으고 `적용` 전까지 임시 상태로 유지.

## 화면 구성

- 왼쪽 현재 프로젝트 버튼 클릭 시 `연결 프로젝트 관리` 모달 표시
- 모달 상단에 현재 등록된 프로젝트 목록 우선 표시
- 각 프로젝트 행에 다음 정보와 기능 제공
  - 프로젝트 폴더명과 전체 경로
  - `현재 작업 프로젝트`, `연결됨`, `경로 없음`, `현재 경로 불일치` 상태
  - 현재 프로젝트로 선택
  - 폴더 열기
  - 경로 다시 선택
  - 연결 목록에서 삭제
- 목록 아래에 `프로젝트 추가` 버튼 제공
- 하단에 `취소`, `적용` 버튼 제공
- 현재 연결이 없을 때 샌드박스 작업공간 사용 상태 표시

## 동작 규칙

- 삭제는 Parley 연결 정보만 제거하며 실제 폴더와 파일은 삭제하지 않음
- 경로 수정은 문자열 직접 입력 대신 폴더 선택기로 다시 지정
- 중복 경로 등록 방지
- 현재 프로젝트 삭제 시 남은 첫 프로젝트를 임시 선택하거나, 목록이 비면 샌드박스로 전환
- `적용` 시에만 `projectDirs`와 `projectDir` 저장
- 현재 작업 경로가 바뀌면 모델 세션이 새로 시작된다는 경고 표시
- 프로젝트 관리 UI는 기존 설정 모달의 연결 프로젝트 영역을 대체하여 중복 제거
- 기존 `작업 폴더 열기` 기능은 모달의 프로젝트별 `폴더 열기`로 이동

## 왼쪽 메뉴 툴팁

- 사용량 메뉴의 시각 스타일을 재사용한 전용 툴팁 적용
- 대상: 현재 프로젝트, 대화 내보내기, 대화 저장 폴더, 사용량, 도구, 설정, 사용 가이드
- 메뉴 이름과 한 줄 기능 설명 표시
- 마우스 오버와 키보드 포커스 모두 지원
- 한국어·영문 번역 제공
- 사용량 메뉴는 기존 그래프 툴팁 유지

## 제외 범위

- 실제 프로젝트 폴더 삭제 또는 이동
- 프로젝트 별칭 별도 저장
- 상단 대화·작업·새 대화 버튼의 툴팁 개편
- 연결 프로젝트 순서 변경 기능

## 검증

- 프로젝트 추가·경로 변경·선택·삭제 후 `적용` 결과 확인
- `취소` 시 변경 미반영 확인
- 중복 경로·없는 경로·현재 경로 불일치 표시 확인
- 프로젝트 폴더를 삭제하지 않는지 확인
- 왼쪽 메뉴 툴팁의 한국어·영문·키보드 포커스 확인
- 관련 단위 검사, 문법 검사, 패키징 확인만 수행
