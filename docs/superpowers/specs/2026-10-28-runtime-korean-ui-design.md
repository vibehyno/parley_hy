# 동적 UI 문구 한글화 설계

## 목적

- 한국어 설정에서 실행 중 생성되는 알림·경고·상태·툴팁의 영어 노출 제거
- 초보 사용자도 권한과 모델 상태를 즉시 이해할 수 있는 자연스러운 한국어 제공

## 범위

- 상단 토스트, 권한·작업 배너, 확인창, 대기열·깨우기·중지 메뉴
- 모델 상태, 메시지 전달 상태, 버튼·아이콘 툴팁, 오류 안내
- 방·폴더·작업공간 관련 동적 안내
- 영어 설정의 기존 문구 유지

## 번역 제외

- 모델명, Skill·MCP·Plugin 이름, 명령어, 파일 경로, 브랜치명
- 사용자가 작성한 대화와 모델 응답 본문
- 외부 CLI가 반환한 원본 오류 상세 — 앞쪽 안내 문구만 번역

## 구현 원칙

- `ui/i18n.js` 키와 변수 치환 사용
- `ui/app.js`의 사용자 노출 문자열을 `t()` 또는 `tr()` 호출로 전환
- 한국어 문구의 짧은 문장과 행동 결과 우선 표시
- 내부 로그·주석·프로토콜 문자열 번역 금지

## 완료 기준

- 제시된 폴더 열기 토스트와 전체 접근 권한 배너 한글 표시
- 주요 동적 UI 영역의 한국어 설정 영어 문구 미노출
- 영문 설정 회귀 없음
- 모델명과 경로 원문 유지
